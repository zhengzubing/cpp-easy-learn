```c++
template<typename... Args>
void forward_to(Args&&... args) {
target_function(std::forward<Args>(args)...);
}
```
Op... args 表示一个一个展开, 展开后每个 arg 都调用 Op
Op(arg) 表示全部展开后再调用 Op


```c++
template<typename T>
void _print(T value) {  // 修正：viod → void
    std::cout << value;
}

template<typename... ArgTs>
void print(ArgTs... args) {
    (_print(args),...);  // 展开参数包并调用_print
}

```
