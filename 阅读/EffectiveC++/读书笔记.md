# 条款 4 确定对象被使用前已先被初始化
1. 为内置对象进行手动初始化, 因为 C++不保证初始化它们;
2. 使用初始化列表而不是构造函数体中赋值;
3. 为免除跨编译单元的初始化次序问题(非局部静态对象（non-local static） 的初始化顺序在不同编译单元（.cpp 文件）之间是未定义的), 使用 local static对象替换 non-local static对象

```c++

    int m_value;
    // 私有构造函数，防止外部创建实例
    Month(int value) : m_value(value) {}

public:
    // 静态成员变量声明
    static const Month Jan;
    static const Month Feb;
    static const Month Mar;
    // ... 其他月份
    
    // 可以添加获取值的方法
    int getValue() const { return m_value; }
};
```

```c++

    int m_value;
```

# 条款 9 绝不在构造和析构过程中调用 virtual函数
确保构造函数和析构函数都没有调用 virtual函数, 而且他们调用的所有函数也都服从这一约束;
即使调用了 virtual函数, 这类调用也不会下降至 derived class;

# 条款 10 令 operator=返回一个 reference to *this
为什么不返回 void?
因为要支持 x = y = 10; 这种语法, 即 x.operator=(y.operator=(10)); 因此y.operator=(10)不能为 void;

为什么不返回 const?
因为要满足++(a = b); 这种语法;

# 条款 11 在 operator=中处理自我赋值
```c++
String& operator=(const String& other) {
    // 1. 自我赋值检查：如果地址地址相同，直接返回
    if (this == &other) {
        return *this;
    }

    // 2. 先释放当前对象的资源有资源
    delete[] data;

    // 3. 分配新内存间并复制数据
    length = other.length;
    data = new char[length + 1];
    std::strcpy(data, other.data);

    // 4. 返回当前对象引用
    return *this;
}
```
或者 更现代的做法, 天然处理自我赋值
```c++
String& operator=(String other) {  // 按值传递，自动创建副本
    std::swap(data, other.data);   // 交换当前对象与副本的资源
    std::swap(length, other.length);
    return *this;
}  
```

# 条款 12 复制对象时勿忘其每一个成分
1. copying函数中, 请确保复制所有 local 成员变量, 调用所有 base classes内的适当的 copying函数.
```c++
    // 派生类拷贝构造函数：必须在初始化列表中调用基类拷贝构造
    Derived(const Derived& other) 
        : Base(other)  // 显式调用基类拷贝构造，传入other（会被隐式转换为Base&）
        , age(other.age) {
        std::cout << "Derived 拷贝构造" << std::endl;
    }
```

```c++
    Derived& operator=(const Derived& other) {
        if (this != &other) {  // 检查自我赋值
            // 1. 先调用基类的拷贝赋值运算符，处理基类部分
            Base::operator=(other);  // 显式调用基类的operator=
            
            // 2. 处理派生类自己的成员
            age = other.age;
        }
        std::cout << "Derived 拷贝赋值" << std::endl;
        return *this;
    }
```

3. 不要尝试在某个 copying函数中调用另一个 copying函数以避免代码重复, 应该将共同机能放进第三个函数中, 并由两个 copying函数共同调用.

# 条款 23 宁以 non-member/ non-friend 替换 member 函数
member 函数带来的封装性比 non-member 函数低;
越多的东西被封装, 越少的人可以看到它, 我们就有越多的弹性去变化它, 应为改变仅仅直接影响看到改变的哪些人事物, 因此, 越多的东西被封装, 我们改变那些东西的能力也越大.

non-member non-friend 函数, 并不增加"能够访问 class 内的 private 成员"的函数数量.

为一个类设计相关功能时，除了类自身的成员函数（负责核心逻辑），还会有许多辅助功能（如格式化输出、数据转换、组合操作等）。这些辅助功能若实现为non-member、non-friend函数，可以按功能模块拆分到不同头文件中，形成 “类的核心定义 + 多个功能扩展头文件” 的结构。

# 条款 25 考虑写出一个不抛异常的 swap 函数
```c++
namespace std {
    // 基础模板实现
    template<typename T>
    void swap(T& a, T& b) {
        T temp = a;  // 拷贝构造临时对象
        a = b;       // 拷贝赋值
        b = temp;    // 拷贝赋值
    }
}
```

```c++
namespace std {
    template<typename T>
    void swap(T& a, T& b) noexcept(
        is_nothrow_move_constructible_v<T> && 
        is_nothrow_move_assignable_v<T>
    ) {
        T temp = std::move(a);  // 移动构造（而非拷贝）
        a = std::move(b);       // 移动赋值
        b = std::move(temp);    // 移动赋值
    }
}
```

提供一个 public swap 成员函数, 
提供一个 non-member swap, 令它调用上述的 swap 成员函数

```c++
// 实现
namespace MyNamespace {  // 类所在的命名空间
    class MyClass {
    public:
        void swap(MyClass& other) noexcept {  // 成员swap，高效交换内部资源
            // 交换内部数据（如指针、大小等）
        }
    };

    // 非成员swap，调用成员函数
    void swap(MyClass& a, MyClass& b) noexcept {
        a.swap(b);
    }
}
```

```c++
// 使用
template<typename T>
void do_something(T& a, T& b) {
    using std::swap;  // 引入std::swap作为备选
    swap(a, b);       // 优先ADL查找，否则用std::swap
}
```

提供的成员函数版 swap 要求不能抛出异常;
