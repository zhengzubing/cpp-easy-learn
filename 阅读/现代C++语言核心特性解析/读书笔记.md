3. int32_t 在 C/C++ 中，基本类型（如 int、long）的大小可能因 平台或编译器 不同而变化。int32_t 的引入解决了这个问题：跨平台一致性：无论编译环境如何，int32_t 始终是 32 位有符号整数。嵌入式/网络编程：在协议、文件格式、硬件交互等场景中，必须确保数据大小精确匹配。
4.  UTF-32是 定长, 但太占用内存空间
    UTF-16是 定长, 特殊编码方法
    UTF-8是 变长, 1-4字节  // char utf8[] = u8"你好世界";
    UTF-8、UTF-16、UTF-32 都能表示全部 Unicode 字符（U+0000 ~ U+10FFFF）。
    UTF-32 不会比 UTF-16 多表示任何字符。
    优先 UTF-8（兼容性好，存储高效）。
